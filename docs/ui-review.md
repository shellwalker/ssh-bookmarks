# 菜单栏与主界面 UI 复查

复查对象是菜单栏面板、站点主窗口、设置窗口和站点编辑表单。没有 Mac 屏幕，结论来自 SwiftUI 代码和 Apple HIG（可发现性、系统菜单、SF Symbols 语义、深浅色、空态与焦点）。标了「待真机」的项需要在浅色 / 深色下实际看一眼。

面板宽度固定 340pt。搜索框需要整行宽度，所以设置和退出放在底栏，不放到顶栏。

## P0（已改）

### 1. 菜单栏面板里找不到设置

应用是 `LSUIElement`。只开着菜单栏面板时，系统菜单栏里的 App 菜单不出现，⌘, 没有可见入口。底栏原来只有一个齿轮，`help` 提示悬停才出现，旁边是电源图标，第一次使用的人不会把它认成「设置」。

- 之前：底栏右侧是无文字的 `gearshape`，设置只靠 ⌘,。
- 现在：底栏有带文字的「设置」按钮（齿轮 + Settings / 设置）。同一底栏的「更多」菜单里有「设置…」并标出 ⌘,。App 菜单的 Settings 命令组同样打开设置窗口。

### 2. 退出用了关机图标

`power` 在 HIG 里表示关机或电源，不表示退出这一个应用。菜单栏常驻工具更不该用它。

- 之前：底栏电源图标，没有「退出」文案。
- 现在：电源图标已去掉。底栏「更多」（`ellipsis.circle`，旁白标签「更多」）里是文字项「退出 MenuSSH」，快捷键 ⌘Q。App 菜单的终止命令组同样是「退出 MenuSSH」⌘Q。中文为「退出 MenuSSH」。

## P1（已改）

### 3. 关于、设置、退出在面板和 App 菜单里都能找到

「更多」菜单：关于 MenuSSH、设置…（⌘,）、分隔线、退出 MenuSSH（⌘Q）。App 菜单对应替换了 About、Settings、Quit 三个命令组。关于会把设置窗口切到「关于」页（`pendingSettingsPane`，窗口出现时消费并清空，不写入 UserDefaults）。

站点主窗口工具栏增加了「设置」齿轮，打开同一设置窗口。工具栏按钮不再单独绑 ⌘,，避免和 App 菜单的 ⌘, 抢同一个快捷键。

待真机：面板成为 key window 时，底栏菜单里的 ⌘, / ⌘Q 和 App 菜单命令是否会各执行一次。退出执行两次没有副作用；设置若开出两个窗口则需要再收一次。

### 4. 「新建分组」看起来像不可点的标签

侧栏底部的「新建分组」原来是无边框按钮，和分组列表混在一起。

- 之前：`.borderless`。
- 现在：`.bordered`、`.controlSize(.small)`，底栏用 `.bar` 背景和列表分开。

### 5. 中文分段控件溢出设置卡片

外观等分段控件使用了 `.fixedSize()`。英文标签能放下，中文「跟随窗口」会把控件撑出卡片。

- 之前：按内容无限变宽。
- 现在：`.controlSize(.small)`，最大宽度 280pt，由卡片在剩余空间里压缩。待真机确认三等分标签是否被截成省略号。

### 6. 终端回退后没有说明，面板还会自己关掉

配置的终端没装时，会话会改用另一台已安装的终端（见 `docs/design-v2.md` 的 B3）。这是一次偏离用户设置的行为，必须留在界面上。

- 之前：没有这类提示；连接成功且打开了「连接后关闭面板」时，面板立即消失。
- 现在：橙色 `info.circle` 一行，文案「未安装 %@，已改在 %@ 中打开本次会话。」菜单栏面板和站点主窗口都显示。有这条提示时不自动关面板。不改已保存的终端偏好。错误仍是红色三角，并清掉这条提示。

## P2（未改，待真机或下一轮）

1. 设置窗口的搜索框用了 `.searchable(placement: .sidebar)`。和参考图（侧栏顶部搜索、右侧面包屑「设置 / 分类」、卡片一行一项）已经接近，但是否贴在侧栏列表正上方、选中行的系统高亮是否盖住图标，要在窗口里看。窗口标题本身就是「设置」，和面包屑第一段重复。
2. 站点编辑仍是系统 `Form`（分组样式），不是 Termius 那种分卡片的编辑器。字段、校验和钥匙串说明是齐的，视觉层级下一轮再对齐。
3. 头像用固定高饱和色加白字。深色模式下对比大概率够，浅色下粉、黄、橙是否发灰要看。收藏星是 `.yellow`，浅色背景下偏亮，深色下可能发荧光。
4. 菜单栏列表里，键盘选中和鼠标悬停共用同一块 `accentColor` 18% 透明高亮。鼠标划过会抢走键盘光标，方向键和悬停会互相覆盖。
5. 主窗口工具栏的「导入 ~/.ssh/config」不显示导入条数。设置页同一操作会写「已导入 N 个站点」。主窗口成功时是静默的，失败才在列表底部出红字。
6. 面板宽度写死 340pt。英文「Manage Hosts」+「Settings」+ 省略号图标是否挤换行，要在 12pt 下看；中文「管理主机」「设置」更短，更可能放得下。
7. 底栏按钮是 `.borderless`。键盘焦点环在无边框按钮上经常看不见，全键盘访问时底栏可能没有焦点提示。
8. 设置搜索结果里的跳转是普通按钮，没有卡片行高和右侧箭头。
9. 站点数据文件路径是卡片下方的等宽小字，没有放进设置行，也不能从这一行打开访达（设置项里另有「在访达中显示」）。

## 需要在 Mac 上核对的行为

这些不改变上面的优先级，但代码推不出来：

- ⌘, 与齿轮是否把设置窗口带到最前，并落到请求的那一页。
- 菜单栏面板作为第一个 Scene 时，启动会不会顺带弹出主窗口（macOS 14 没有 `defaultLaunchBehavior(.suppressed)`）。
- 「跟随窗口」是否把 MenuBarExtra 的面板误认成普通窗口。
- 深色 / 浅色下头像、黄星、橙色提示、红色错误的对比。
- 底栏在英文和中文下是否单行；省略号菜单的点击热区是否够大。
- 自动化被拒绝（-1743）时，提示里的终端名是实际拿去执行 AppleScript 的那一个，而不是用户原来选的那个。
